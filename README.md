Wireframe for Random Zotero built on Python3/Flask.

NB: You need to add an .env file to make this work. DO NOT COMMIT THIS FILE TO VERSION CONTROL. (It should be excluded by .gitignore.) The .env file should look like this:

```
APP_SETTINGS="config.DevelopmentConfig"
LIBRARY_ID='{REPLACETHIS}'
LIBRARY_TYPE='{REPLACETHIS}'
API_KEY='{REPLACETHIS}'
```
